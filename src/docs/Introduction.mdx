# Northwind UI

A small design system built on MUI (Material UI).

- **Tokens** start in Figma and flow into an MUI theme.
- **Components** wrap MUI with a small API. Product code imports from `@northwind/ui`, never from `@mui/material`.
- **Agents** read this Storybook through the Storybook MCP server.

Components appear here from step 4.
